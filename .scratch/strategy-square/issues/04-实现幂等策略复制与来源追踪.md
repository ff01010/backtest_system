# 04: 实现幂等策略复制与来源追踪

**Spec:** `docs/44_策略广场与共享回测方案.md` §4.5、§5.3、§9.2–9.3、§10.3、§12

**What to build:** 让用户把一条已上架的普通共享回测复制为自己独立拥有的完整策略，不自动运行；重复复制返回已有副本，并在策略、副本回测和后续衍生共享中永久保留来源归属。

**Blocked by:** 01: 建立共享回测核心链路

**Status:** done

- [x] 复制创建独立策略方案、独立脚本身份和不可变脚本版本，不共享可变记录。
- [x] 复制代码、策略参数、标的、周期、基准、成交模型和执行参数，并清除原账户关联。
- [x] 新策略使用“共享标题-副本”及现有重名规则，复制成功后打开编辑器且不创建回测。
- [x] 同一接收者重复或并发复制同一共享回测只创建一个副本并幂等返回。
- [x] 复制次数只在首次成功创建直接副本时增加一次。
- [x] 策略及其回测快照保留共享编号、原作者和原共享标题，来源不参与策略执行或草稿指纹。
- [x] 衍生回测可以再次共享并显示来源，但不能直接重复上架他人的共享快照。
- [x] 增加事务回滚、并发幂等、账户清除、来源传递和前端复制体验测试。
