# 02: 完善作者生命周期与“我的共享”

**Spec:** `docs/44_策略广场与共享回测方案.md` §4.6、§5.2、§7、§8、§10.4、§12

**What to build:** 让共享回测作者能够在“我的共享”中查看全部状态、修改独立展示信息、撤回并重新上架，同时保证核心快照、首次上架时间和统计不被改变，原任务或作者账号变化也不破坏共享内容。

**Blocked by:** 01: 建立共享回测核心链路

**Status:** done

- [x] 作者可以分页查看本人 `active`、`withdrawn`、`removed` 条目及真实状态。
- [x] 作者可以修改共享标题、说明和标签，但不能修改核心快照、摘要、署名或来源。
- [x] 状态转换严格限制为作者 `active -> withdrawn`、本人 `withdrawn -> active`。
- [x] 重新上架保留共享编号、首次上架时间、收藏关系、复制次数和核心摘要。
- [x] 原回测、原策略删除后共享内容仍可用；作者账号删除后保留姓名快照并改由管理员管理。
- [x] 前端提供“我的共享”、编辑、撤回、重新上架和不可用状态展示。
- [x] 增加生命周期、权限、兼容和前端交互测试。
