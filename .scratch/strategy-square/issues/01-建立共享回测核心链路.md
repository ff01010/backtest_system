# 01: 建立共享回测核心链路

**Spec:** `docs/44_策略广场与共享回测方案.md` §4.1–4.3、§5.1、§6、§7、§8、§9.1、§10.1–10.2、§13

**What to build:** 让用户能够从本人资料完整的成功历史回测创建一条独立、不可变的共享回测，并让其他正常登录用户在策略广场基础列表和详情中看到安全投影。该切片必须贯通数据库、后端接口、前端入口与自动化测试，同时保持原策略和原回测的所有权隔离不变。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 新增幂等迁移，建立共享回测核心表、版本化快照、生命周期字段、必要索引和强制 RLS。
- [x] 仅允许所有者上架 `succeeded` 且代码、参数和结果快照完整的任务；旧任务缺少资料时返回明确错误。
- [x] 使用业务字段白名单生成快照与摘要，不暴露账户、路径、请求键或系统诊断。
- [x] 同一原回测并发或重复上架只产生一条共享回测并幂等返回。
- [x] 提供已登录用户可用的基础列表和详情接口，未登录及非 `active` 普通读取被拒绝。
- [x] 历史回测页面提供共享表单，策略广场提供可演示的基础列表与详情入口。
- [x] 增加数据库、后端和前端测试，证明跨用户只能读取共享投影，不能读取未共享原资源。
