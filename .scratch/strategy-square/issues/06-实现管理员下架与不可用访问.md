# 06: 实现管理员下架与不可用访问

**Spec:** `docs/44_策略广场与共享回测方案.md` §4.7、§5.2、§7、§8、§10.4

**What to build:** 让管理员能够对已上架共享回测执行带原因下架和恢复，让作者查看处置原因，同时确保普通用户通过列表、收藏、旧链接或缓存都只能得到统一不可用结果。

**Blocked by:** 02: 完善作者生命周期与“我的共享”

**Status:** ready-for-agent

- [ ] 只有管理员可以执行 `active -> removed` 和 `removed -> active`。
- [ ] 下架原因必填并记录操作者与时间，恢复保留原共享编号、统计、收藏和首次上架时间。
- [ ] 作者可以在“我的共享”查看下架时间和原因，但不能自行恢复。
- [ ] 普通用户无法区分撤回、下架和不存在，也不能读取已缓存的代码、参数、结果或附件。
- [ ] 管理员界面提供下架、原因填写、查看和恢复入口，不新增事前审核流程。
- [ ] 增加管理员角色、作者可见性、普通用户负向访问和前端缓存清理测试。
