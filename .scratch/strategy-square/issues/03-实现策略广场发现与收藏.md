# 03: 实现策略广场发现与收藏

**Spec:** `docs/44_策略广场与共享回测方案.md` §4.2、§4.4、§5.3、§8、§10.1

**What to build:** 让正常登录用户能够高效发现共享回测，按标题、作者、标的和标签搜索，按策略类别与周期筛选，使用稳定分页和已确认排序，并将感兴趣的条目收藏到个人列表。

**Blocked by:** 01: 建立共享回测核心链路

**Status:** ready-for-agent

- [ ] 列表提供标题、作者、标的、标签搜索以及策略类别、周期筛选。
- [ ] 支持按首次上架时间和复制次数稳定排序，不提供收益排行榜。
- [ ] 列表响应包含复制次数、当前用户收藏状态和已复制状态，但不返回完整代码或结果。
- [ ] 收藏和取消收藏幂等，同一用户与共享回测只有一条收藏关系。
- [ ] 撤回或下架不删除收藏关系，普通收藏列表不泄露不可用条目详情。
- [ ] 前端提供“全部共享”“我的收藏”、筛选排序、分页、空状态和不可用处理。
- [ ] 增加查询稳定性、收藏权限、撤回恢复和前端交互测试。
