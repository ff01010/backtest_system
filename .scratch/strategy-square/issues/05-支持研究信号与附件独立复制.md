# 05: 支持研究信号与附件独立复制

**Spec:** `docs/44_策略广场与共享回测方案.md` §3.2、§4.1、§4.5、§5.4、§9.1–9.2、§11

**What to build:** 让依赖研究信号或附件的成功回测也能完整共享和复制。共享时形成独立共享附件，复制时导入为接收者自己的可回测依赖，作者撤回、下架或删除原任务后不影响已有副本。

**Blocked by:** 04: 实现幂等策略复制与来源追踪

**Status:** done

- [x] 新增幂等迁移和权限策略，建立共享附件及接收者导入所需的数据关系。
- [x] 上架时复制复现所需的研究信号快照和附件，校验内容摘要，不依赖原任务继续存在。
- [x] 共享详情只返回受控附件元数据和鉴权读取入口，不暴露内部存储键或路径。
- [x] 复制时为接收者创建新的可预检研究信号数据身份和独立附件，不沿用原作者授权或数据集 ID。
- [x] 暂存文件、数据库写入或数据导入任一步失败时完整清理，不产生可见半成品或错误复制计数。
- [x] 撤回、下架和原资源删除后，已经复制的依赖仍可由接收者正常使用。
- [x] 增加摘要校验、权限、失败清理及带研究信号回测的集成测试。
