# 回测系统使用说明

本说明面向系统管理员和普通使用者，介绍日常使用方式。系统不开放自主注册，所有账号由管理员统一创建。

## 1. 登录系统

1. 打开系统地址后，会先进入登录页。
2. 输入管理员创建的用户名和密码，点击“登录系统”。
3. 初始管理员账号为：
   - 用户名：`admin`
   - 密码：`123456`
4. 管理员首次登录后，建议马上在“人员管理”中重置自己的密码。
5. 右上角点击“退出”即可结束当前登录。

如果提示“登录已失效”，重新登录即可。管理员重置某个用户密码或禁用账号后，该用户原有的登录状态会失效。

## 2. 管理员：人员管理

只有管理员能看到顶部的“人员管理”。

### 创建账号

1. 打开“人员管理”。
2. 填写用户名、姓名、初始密码和角色。
3. 点击“创建”。

用户名建议使用英文、数字、下划线、短横线或点号，例如 `zhangsan`、`li.si`。

### 修改账号

- 可以把用户设为“普通用户”或“管理员”。
- 可以启用或禁用账号。禁用后用户不能再登录，但其策略、方案和历史记录不会被删除。
- 可以点击“重置密码”为用户设置新密码。
- 系统至少保留一名启用的管理员，最后一名启用管理员不能被降级或禁用。

## 3. 用户能看到哪些内容

- 普通用户只能看到并管理自己的：标的、回测账户、策略脚本、策略方案和回测记录。
- 普通用户无法查看其他用户的策略代码、回测结果和数据同步记录。
- 管理员也按自己的策略库使用系统。初始示例策略只放在管理员策略库中，普通用户初始没有策略。
- 所有用户共用管理员导入的 QMT 历史行情。行情保存在 ClickHouse，用户不能在回测时临时联网拉取或修改行情。

## 4. 策略使用流程

策略回测按下面顺序进行：

1. 新建或编辑策略脚本和方案参数。
2. 点击“保存策略”。
3. 运行回测。

系统不要求用户维护“草稿/发布版本”。每次回测都会保存当时的策略代码、说明、参数、方案和行情快照，历史结果可独立追溯。

## 5. 新建策略脚本

1. 进入“策略回测”页面。
2. 在策略脚本区域点击新建，填写策略名称、说明和 Python 代码。
3. 保存后，脚本会出现在自己的策略库中。

脚本需要定义下面这个函数：

```python
def on_bar(bar, state):
  return []
```

- `bar` 是当前一根 K 线的信息，例如时间、开高低收、成交量和当前仓位。
- `state` 用于保存策略自己的运行状态和方案参数。
- 函数返回订单列表；没有交易信号时返回 `[]`。

可用订单动作：

- `buy_open`：开多仓。
- `sell_open`：开空仓。
- `sell_close`：平多仓。
- `buy_close`：平空仓。

每条订单至少需要包含动作和数量，例如：

```python
[
  {
    'action': 'buy_open',
    'quantity': 100,
    'reason': '示例买入信号'
  }
]
```

策略运行在独立的执行容器中。它可以使用镜像中已有的 Python 模块，但不能访问系统数据库、服务器宿主机目录或其他用户的文件。

## 6. 保存策略

1. 选择一个策略脚本。
2. 填写标的、周期、资金、手续费、交易方向和策略参数。
3. 填写方案名称，点击“保存策略”。

保存会覆盖该策略当前内容。修改后再次保存即可；已有回测记录不受影响，因为它们保留了独立快照。

## 7. 运行回测

1. 选择已保存的策略方案。
2. 选择回测标的和对比基准；没有单独选择基准时，系统使用回测标的作为基准。
3. 设置开始日期、结束日期、初始资金、手续费、滑点和持仓规则。
4. 点击“运行回测”。

当前支持 `1m` 和 `5m` 分钟回测。

回测只读取管理员事先导入 ClickHouse 的 QMT 历史数据。标的、周期或日期区间未覆盖时，系统会明确提示缺失范围，不会自动从外部接口下载。

若数据源暂时不可用、数据不完整或日期范围没有可用行情，系统会提示原因，不会使用不完整数据生成回测结果。

## 8. 查看回测结果和历史

回测完成后，可以查看：

- 收益、收益率、最大回撤、胜率等汇总指标。
- 权益曲线和基准曲线。
- 每日持仓和资金变化。
- 成交明细，包括成交时间、方向、价格、数量和盈亏。
- 回测记录对应的策略快照、方案参数快照和 QMT 数据快照。

历史记录只对创建该记录的用户可见。

## 9. 数据管理

“数据管理”页面用于查看个人常用标的和 QMT 数据覆盖情况。

- 可以添加、编辑或停用自己的常用标的。
- 可以检查某个标的和周期是否已经覆盖所选日期范围。
- QMT 原始文件导入由管理员在服务器执行，不在普通用户页面直接上传。

QMT 行情是全局共享的，但个人常用标的列表和回测记录仍保持隔离。

## 10. 常见问题

### 为什么点击回测后等待较久？

通常是所选标的、周期或日期区间尚未导入 QMT 历史数据。请在页面中确认缺失范围，并由管理员导入对应原始文件后再运行。

### 为什么没有“发布新版本”按钮？

策略以当前保存内容为准。每次回测都保存策略和参数快照，因此即使之后继续修改策略，也可以准确查看历史回测当时使用的内容。

### 为什么看不到其他人的策略或回测？

这是正常的权限隔离。每个账号只管理自己的策略库、方案、账户和回测记录。

### 为什么管理员不能删除用户？

系统采用“禁用”而不是物理删除，避免误删用户的策略和历史记录。需要停止使用某账号时，将其设为“已禁用”。

### 为什么回测被拒绝？

请依次检查：

1. 是否选择了已保存的策略方案。
2. 普通用户是否已经发布策略版本。
3. 标的代码、日期范围和周期是否正确。
4. 数据源是否可用，或该日期范围是否确实存在分钟行情。
5. 策略脚本是否满足 `on_bar(bar, state)` 的格式，订单数量是否为正整数。
