# 共享回测采用独立不可变的共享边界

跨用户展示和复制以独立的“共享回测”为边界，而不是给 `backtest_run` 增加公开标记，也不复用 `strategy_config.published`。上架时按版本化白名单冻结一次成功回测的策略、参数、结果及复现依赖；原策略、原回测和原附件继续保持现有所有者隔离，后续修改或删除不改变共享快照。

这一选择使作者撤回、管理员下架、作者账号变化和原任务删除都不会破坏已经生成的策略副本，也避免“策略发布”同时承担可运行版本与跨用户可见性两种含义。代价是需要独立保存较大的结果与附件、维护快照版本，并为共享读取、附件访问和复制建立单独的权限与一致性校验。

策略副本必须复制为接收者独立拥有的完整策略及依赖，不持续引用仍受原作者生命周期控制的资源；来源信息作为不可变归属记录保留。现有个人策略、回测、开放 API 和附件的行级隔离不得为实现策略广场而放宽。
