# ADR 0001：提供通用运行能力，不内置方向性策略

- 状态：已接受
- 日期：2026-08-29
- 关联方案：[标准 Bar 分钟数据派生日线与方向性持仓运行支持方案](../32_标准Bar分钟数据派生日线与方向性持仓运行支持方案.md)

## 背景

需求包含以 MA、斜率、MACD 等日线指标产生方向信号的策略示例。该示例用于说明回测引擎所需能力，而不是要求平台内置某一策略或研究模块。若把示例策略写入平台，会把策略假设、参数口径和收益解释错误地固化为系统职责。

## 决定

系统只提供以下通用能力：完整分钟数据派生的日线 Bar、`on_bar` 日线回调、状态预热、下一可交易 Bar 开盘成交、跨日方向性持仓和可追溯的数据快照。

用户自行编写策略代码；本期不内置 MA、斜率、MACD 规则，不建设预测准确率、每日预测明细、方法比较或参数寻优，也不建设真实券源、融券费率、保证金和同 Bar 原子反手。

## 后果

- 回测引擎的验收聚焦于数据时序、执行语义、预热隔离与结果可追溯性，而不评价具体信号的投资表现。
- 策略示例可作为测试夹具，但不能成为产品内置交易策略或默认参数。
- 真实融券和原子反手仍需独立需求、风控边界与执行模型评审后再实施。

## 排除的替代方案

1. 内置 MA/斜率/MACD 策略：会将业务需求绑定到单一策略口径，且超出运行时支持范围。
2. 同期建设预测研究模块：与历史回测执行能力没有必要依赖，会扩大数据模型和验收范围。
