# ADR 0002：标准 QMT Bar 的单一来源选择

- 状态：已接受（`3m`、`45m` 派生周期部分已由 ADR 0010 取代）
- 日期：2026-08-29（2026-09-28 修订为单一 QMT 数据库来源）

## 决定

标准 QMT Bar 链路不改变 L2 映射链路。沪、深、北交所统一只使用 `qmt_history_dev`：原生读取对应的六周期表，平台 `60m` 映射物理 `1h`，`3m`、`45m` 由同库的 `1m` 数据派生。界面只展示该库发布元数据声明的可回测范围，保存和提交不做行情完整性预检。Worker 按该标的已发布覆盖日期读取行情；请求区间没有可用日期、超出来源边界或预热天数不足时任务失败，并向用户统一提示“行情数据异常，请联系管理员”，不切换其他 QMT 数据库。

`qmt_ingest_runs` 的发布校验结果与 `qmt_universe_snapshot` 的标的成员关系共同表达可用范围。保存和提交不依赖交易日历；Worker 以该范围内状态完整的日期作为实际回放日期，并从同一来源寻找预热日期。标准 Bar 回放读取已定稿的原始行，不按 `quality_status` 筛选，不核对已选覆盖日期是否逐日都有实际 Bar；完全无 Bar、字段无法解析或查询失败仍属于执行错误。行情质量由数据发布与维护流程负责，L2 质量规则不在本次变更范围内。

页面范围查询只读取 `qmt_ingest_runs` 与 `qmt_universe_snapshot`。查询超时和临时网络错误使用有限重试；没有标的覆盖、重试耗尽或发生 SQL、权限、表结构等确定性错误时按无可用范围或数据源异常结束，不能静默切换其他数据库。

新任务只保存 `qmt_history_dev` 来源快照。尚未执行且快照指向已移除 QMT 来源的历史任务明确失败，不根据当前来源重算或改写；发布前必须先排空或处理这类任务。已完成任务继续读取已保存结果。

## 后果

- 标准 QMT Bar 运行时不再依赖其他 QMT 数据库及其覆盖表。
- 同一任务只使用 `qmt_history_dev` 的一个原始周期或由其完整 `1m` 数据派生。
- L2 日线复用需求需独立评审，避免扩大本期回归范围。
