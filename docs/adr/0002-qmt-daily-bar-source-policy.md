# ADR 0002：标准 QMT Bar 的单一来源选择

- 状态：已接受
- 日期：2026-08-29（2026-09-19 更新来源优先级）

## 决定

标准 QMT Bar 链路不改变 L2 映射链路。来源解析先计算预热与正式区间合并后的目标范围，再选择一个完整覆盖该范围的来源：沪、深、北交所统一优先使用 `qmt_history_dev` 对应的原生六周期表；新库不能完整覆盖时，整次任务回退到 `raw_historical_data.qmt_kline`。两者均不足则阻止提交。

两套完整度语义保持独立：新库沿用 `qmt_ingest_runs` 的发布校验规则，旧库沿用 `qmt_kline_coverage` 的 `complete` 状态。交易日历只服务日期展示，不是回测数据可用性的前置依赖。

## 后果

- 同一任务不会跨新旧数据库或不同原始周期拼接数据。
- 平台 `60m` 映射新库物理 `1h`；`3m`、`45m` 在所选数据库内由完整 `1m` 数据派生。
- L2 日线复用需求需独立评审，避免扩大本期回归范围。
