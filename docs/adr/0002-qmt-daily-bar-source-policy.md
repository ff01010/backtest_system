# ADR 0002：标准 QMT 日线的单一来源选择

- 状态：已接受
- 日期：2026-08-29

## 决定

本期只改造标准 QMT Bar 链路，不改变 L2 映射链路。来源解析先计算预热与正式区间合并后的目标范围，再选择一个完整覆盖该范围的来源：完整原始 `1d` 优先，否则使用完整 `1m` 派生 `1d`；两者均不足则阻止提交。

完整度唯一以 `qmt_kline_coverage` 的 `complete` 状态判定。交易日历只服务日期展示，不是回测数据可用性的前置依赖。

## 后果

- 同一任务不会跨原始日线和分钟派生日线拼接数据。
- L2 日线复用需求需独立评审，避免扩大本期回归范围。
