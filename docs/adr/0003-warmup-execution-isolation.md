# ADR 0003：预热作为执行器无交易阶段

- 状态：已接受
- 日期：2026-08-29（2026-09-22 修订校验时机）

## 决定

`warmupTradingDays` 仅适用于标准 Bar 自定义策略，范围为 `0–250`，默认 `0`。执行器显式区分预热与正式阶段：预热期调用 `on_bar` 并保留策略状态，但禁止订单接纳、成交、费用、资金/持仓/净值变化及任何结果事件落盘。

保存和提交不校验预热行情。Worker 执行阶段使用交易日历寻找正式与预热的开市日，再按标的覆盖元数据选择单一来源；停牌日不计入该标的实际预热天数。无法取得请求数量的可用预热交易日时任务失败，并按统一行情数据异常提示用户。
