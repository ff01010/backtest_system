# 前端浏览器运行环境记忆

## 适用范围

修改前端浏览器 API、任务创建、幂等键、重复提交保护或异步错误提示时，必须读取本文。目标是避免测试环境支持某个浏览器能力，而实际内网部署环境不支持，最终导致请求在发送前失败且页面没有可见反馈。

## 已知部署边界

- 系统可能通过内网 IP 的 HTTP 地址访问，不得假定生产浏览器一定处于安全上下文。
- 账号密码解决身份认证和业务授权，不会让 HTTP 页面成为浏览器安全上下文。
- 使用受安全上下文限制的 Web API 前，必须进行能力检测；测试环境中的 JSDOM 或 Node.js 提供该 API，不能证明实际浏览器也提供。

## 2026-09-19 批量导出事件

### 症状

历史回测选择记录后，点击“批量导出信号明细”没有可见反应。用户怀疑任务已在服务端排队但前端没有通知，并可能因重复点击创建多个任务。

### 根因

前端在发送创建请求前直接调用 `crypto.randomUUID()` 生成 `Idempotency-Key`。内网 IP 的 HTTP 页面不提供该安全上下文限定能力，因此代码在请求发出前抛出异常，服务端没有创建任务。

异常虽然被捕获，却写入了只在策略编辑区域展示的通用错误状态；历史回测页面没有渲染该错误，所以用户看到的是“点击无效”。

### 排除的错误判断

- 不是导出执行器排队但前端没有轮询：当时执行器健康，当前账号没有导出任务。
- 不是幂等键冲突：创建接口根本没有收到请求。
- 不是按钮缺少成功反馈：创建成功路径原本会清空选择并打开导出记录抽屉。

## 强制规则

### 浏览器能力

- 使用浏览器 API 时先检查实际能力，不以协议、登录状态、测试环境或 TypeScript 类型声明代替运行时检测。
- 用于非安全业务语义的随机 UUID 必须保留兼容路径：优先使用 `crypto.randomUUID()`，不可用时使用 `crypto.getRandomValues()` 生成符合 UUID v4 版本位和变体位要求的值。
- 功能如果确实依赖安全上下文，应检查 `window.isSecureContext` 并在当前操作区域给出明确提示，不得表现为无响应。

### 异步创建与幂等

- 用户发起创建后立即进入提交中状态并禁用触发按钮；提交完成前的连续点击只能产生一次创建调用。
- 同一次网络自动重试必须复用原 `Idempotency-Key`；只有新的用户主动操作才生成新键。
- 创建成功后必须给出当前页面可见反馈，并提供任务状态或结果入口。

### 错误反馈

- 错误必须显示在用户当前操作所在的页面、面板或抽屉中；不得只写入其他页面才会渲染的通用状态。
- 捕获异常后应保留当前选择，使用户可以根据错误提示重试；选择范围改变时清理旧错误，避免错误跨操作残留。

## 回归完成标准

涉及上述范围的改动至少验证：

1. 模拟 `crypto.randomUUID` 不存在，仍生成格式正确的 UUID v4 并发出创建请求。
2. 创建请求未完成时连续点击，接口只调用一次。
3. 创建失败时，用户在当前操作区域能看到服务端或兼容性错误。
4. 创建成功时，选择被清理并打开任务记录入口。
5. 相关前端测试、TypeScript 检查和正式构建通过；完整测试中的无关失败必须单独复跑并如实记录。
