# Triage Labels

工程技能使用以下五个标准分流角色：

| 工程技能角色 | OpenProject 分流标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护人员评估 |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工处理或决策 |
| `wontfix` | `wontfix` | 确认不处理 |

这些标签作为工程技能的统一分流词汇。没有获得远程写入授权时，只在生成的工单内容中建议标签，不自动修改 OpenProject。
